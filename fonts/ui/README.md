# UI fonts

Syne (variable, 400–800) and Syne Mono (regular) are bundled without modification from the Google Fonts repository to avoid runtime font-service requests.

- https://github.com/google/fonts/tree/main/ofl/syne
- https://github.com/google/fonts/tree/main/ofl/synemono

The respective copyright and SIL Open Font License texts are retained in Syne-OFL.txt and SyneMono-OFL.txt. Downloaded 2026-10-01.
