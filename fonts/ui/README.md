# UI fonts

Syne (variable, 400–800) and Syne Mono (regular) are bundled without modification from the Google Fonts repository to avoid runtime font-service requests.

- https://github.com/google/fonts/tree/main/ofl/syne
- https://github.com/google/fonts/tree/main/ofl/synemono

The respective copyright and SIL Open Font License texts are retained in Syne-OFL.txt and SyneMono-OFL.txt. Downloaded 2026-10-01.

2026-11-19: the interface text uses Geist and Pretendard; Syne stays for the wordmark.

- Geist (variable, 100–900), `Geist-Variable.woff2`, from the npm package `geist` 1.9.2 (Vercel with basement.studio), unmodified. Licence: SIL Open Font License 1.1, `Geist-OFL.txt`.
- Pretendard Variable (45–920), the 92 Unicode-range files in `pretendard/`, from the npm package `pretendard` 1.3.9 (dist/web/variable/woff2-dynamic-subset, Kil Hyung-jin, Reserved Font Name "Pretendard"), unmodified; the @font-face rules are in `src/fonts-pretendard.css`. Licence: SIL Open Font License 1.1, `Pretendard-OFL.txt`.
